    <h2 id="apresentacao">APRESENTAÇÃO</h2>
    <p> A seguir, falarei com minhas palavras o que aprendi com as aulas de HTML. </p>

    <h3 id="title">TAG TITLE </h3>    
    <small><a href="#inicio">(voltar)</a></small>
    <p>A tag <b><i>title</i> </b>, refere-se ao título que será dado a página.</p>

    <h3 id="head">TAG HEAD</h3>
    <small><a href="#inicio">(voltar)</a></small>
    <p> A tag <b><i>head</i></b>, refere-se aos links de estilos e o título da página.</p>

    <h3 id="h1">TAG H1 AO H6</h3>
    <small><a href="#inicio">(voltar)</a></small>
    <p> A tag <strong><i>h1</i></strong>, são os títulos e subtitulos, sendo o h1 o maior e o h6 o menor.</p>

    <h3 id="hr">TAG HR</h3>
    <small><a href="#inicio">(voltar)</a></small>
    <p> A tag <strong><i>hr</i></strong>, é a inclusão de uma linha abaixo do título do texto.</p>

    <h3 id="ol">TAG OL</h3>
    <small><a href="#inicio">(voltar)</a></small>
    <p> A tag <strong><i>ol</i></strong>, representa uma lista ordenada, onde junto com a tag <strong><i>li</i></strong>,(que significa "lista") faz com que cada informação fique em uma linha.</p>

    <h3 id="ul">TAG UL</h3>
    <small><a href="#inicio">(voltar)</a></small>
    <p> A tag <strong><i>ul</i></strong>, refere-se a uma lista não ordenada, também utilizada com a tag <strong><i>li</i></strong>. </p>

    <h3 id="body">TAG BODY</h3>
    <small><a href="#inicio">(voltar)</a></small>
    <p> A tag <strong><i>body</i></strong>, refere-se ao corpo do texto.</p>

    <h3 id="a">TAG A E TARGET</h3>
    <small><a href="#inicio">(voltar)</a></small>
    <p> A tag <strong><i>a</i></strong>, inclui um link no texto, e junto com a tag <i><strong>target</strong></i> faz com que o site abra em uma aba nova. </p>
         <a style="font-size: 24px;"href="index.html" title="clique aqui" < target="_blank"> Meu site </a>

    <h3 id="a">TAG INPUT</h3>
    <small><a href="#inicio">(voltar)</a></small>
    <p> A tag <strong><i>input</i></strong>,  serve para criar campos interativos que permitem coletar dados inseridos pelo usuário, como textos, senhas, e-mails, números, datas, caixas de seleção e arquivos. </p>

    <h3 id="a">TAG IMG</h3>
    <small><a href="#inicio">(voltar)</a></small>
    <p> A tag <strong><i>img</i></strong>, permite a inclusão de imagens ao site.</p>
